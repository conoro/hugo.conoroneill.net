About Me

I’m Conor O’Neill, based in Bandon, Cork, Ireland. I’ve been blogging since 2001 about technology, startups, running, making, and whatever else catches my attention.

About This Blog

Cross Dominant (a.k.a. mixed laterality) has been my home on the web for over two decades. It started on Blogger, moved through WordPress and a few other platforms, and now runs on Hugo.

Topics range from Android and Raspberry Pi to Arduino, IoT, cloud computing, and the occasional rant.
