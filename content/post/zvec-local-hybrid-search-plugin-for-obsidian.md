I recently created a local hybrid search plugin for [Obsidian](https://obsidian.md), powered by [ZVec](https://zvec.org/en/). The original announcement is over on my Substack [Atomic Currents](https://atomiccurrents.substack.com/p/an-all-new-hybrid-search-plugin-for).

I've used it heavily over the past two weeks and it has proven invaluable. It just works better for me than anything else I've tried. As a result, I decided to bundle it up and make it a proper Community Plugin with single click install from Obsidian itself.

You can see it in the [Obsidian Community Plugin Directory here](https://community.obsidian.md/plugins/zvec-hybrid-search).

I don't intend to make any major additions to the functionality as it "just works" for me. The only two improvements since the first release are date filters and making sure it searches front-matter/metadata from other plugins like Web Clipper.

However if you spot bugs or any bad behaviour, please [open an issue on GitHub](https://github.com/conoro/obsidian-zvec-hybrid-search/issues). I'll obviously stay on top of security alerts etc.
